# Acceptance Criteria

Convert a feature request into testable acceptance criteria and identify missing decisions.

## Use in ChatGPT or Claude

Copy the instructions from [SKILL.md](SKILL.md) into a conversation and supply your material. In an Agent Skills environment, install the entire folder using that environment's skill loader.

## Try it

Members may cancel more than two hours before an event. At two hours or less the button is disabled.

**Expected behavior**

Cover 121 minutes, exactly 120 minutes, and 119 minutes before the event. Only the first case permits cancellation.
